# Languages

When the site has more than one language, each entry has a version in
each. The first language is the main one: its pages have no prefix in
their address (`/about`), the others do (`/id/about`).

## Translating

Open an entry and pick a language, then **Add**: it starts as a copy of the
main language, to translate and publish on its own.

Some fields are the same in every language (an image, a price): you change
them in the main language only.

## Menus and other text

Menu labels, globals and terms have a value per language too; leave a menu
label empty to use the page's own title.
